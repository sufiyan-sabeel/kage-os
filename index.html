Setup Guide

Kage OS / Termux Setup

Step-by-step commands to set up your development environment on Android

termux ~ bash
1 Prepare Termux
pkg update && pkg upgrade -y pkg install proot-distro -y
2 Ubuntu & Storage
termux-setup-storage proot-distro install ubuntu
3 Login to Linux
proot-distro login ubuntu --bind /storage/emulated/0:/mobile_storage
4 Install Node.js
apt update && apt upgrade -y apt install curl -y curl -fsSL https://deb.nodesource.com/setup_20.x | bash - apt install -y nodejs
5 Install OpenCode
npm i -g opencode-ai
6 Run in Phone Storage
cd /mobile_storage/Download mkdir AI_Projects && cd AI_Projects opencode-ai or opencode
