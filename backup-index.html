AI Tools

AI Coding Assistants

Install OpenCode, OpenClaw, and OpenClaude on Termux

OC
OpenCode - AI Coding Agent
Official AI coding assistant for terminal (npm method)
pkg update && pkg upgrade -y pkg install proot-distro -y termux-setup-storage proot-distro install ubuntu proot-distro login ubuntu --bind /storage/emulated/0:/mobile_storage apt update && apt upgrade -y apt install curl -y curl -fsSL https://deb.nodesource.com/setup_20.x | bash - apt install -y nodejs npm i -g opencode-ai cd /mobile_storage/Download mkdir AI_Projects && cd AI_Projects opencode-ai
OC
OpenCode - Native Termux Binary
Pre-compiled aarch64 binary (no proot needed)
curl -LO https://github.com/guysoft/opencode-termux/releases/latest/download/opencode-aarch64.zip unzip opencode-aarch64.zip chmod +x opencode mv opencode $PREFIX/bin/ pkg install ripgrep opencode
OC
OpenCode - One-Line Install
Official install script (auto-detects platform)
curl -fsSL https://opencode.ai/install | bash
OC
OpenClaw - AI Gateway
Self-hosted AI assistant framework with Telegram support
pkg update && pkg upgrade -y pkg install proot-distro -y termux-setup-storage proot-distro install ubuntu proot-distro login ubuntu apt update && apt upgrade -y apt install -y curl git build-essential curl -fsSL https://deb.nodesource.com/setup_22.x | bash - apt install -y nodejs npm install -g openclaw@latest openclaw onboard --install-daemon
OC
OpenClaw - Automated Installer
One-command auto installer with Android Error 13 fix
curl -sL https://s.zhihai.me/openclaw_en > openclaw-install.sh && source openclaw-install.sh
OC
OpenClaw - Termux CLI Package
Direct npm install for Termux CLI usage
npm install -g openclaw-termux openclawx setup openclawx start
OC
OpenClaude - Open Source Claude Code
Run Claude Code agentic interface with any AI model
pkg update && pkg upgrade -y pkg install git nodejs python -y git clone https://github.com/techjarves/open-claude-code-termux.git cd open-claude-code-termux bash setup.sh

Termux Theme Installers

Make your terminal look premium with these theme tools

TH
T-Header - Premium Terminal Branding
Custom logos, titles, ZSH themes, keyboard layouts (752 stars)
pkg update && pkg upgrade -y pkg install git figlet -y git clone https://github.com/remo7777/T-Header cd T-Header bash t-header.sh
TL
T-LOAD - Termux Loading Banner
Animated loading screen banner for Termux (138 stars)
pkg update && pkg upgrade -y pkg install git -y git clone https://github.com/ExpertAnonymous/T-LOAD cd T-LOAD bash t-load.sh
TS
tstyle - Font & Color Customizer
Quickly change Termux fonts and color schemes (457 stars)
pkg update && pkg upgrade -y pkg install git -y git clone https://github.com/htr-tech/tstyle cd tstyle bash setup.sh
TS
termux-style - Color Schemes & Fonts
Official Adi1090x script with 80+ themes (1.7k stars)
pkg update && pkg upgrade -y pkg install git ncurses-utils -y git clone https://github.com/adi1090x/termux-style cd termux-style ./install
SS
Termux Super Shell - Zsh + Powerlevel10k
Complete Zsh setup with autosuggestions and syntax highlighting
curl -fsSL https://raw.githubusercontent.com/ahksoft/Termux-SuperShell/code/setup-super-shell.sh -o ~/setup-super-shell.sh && chmod +x ~/setup-super-shell.sh && bash ~/setup-super-shell.sh

Termux:Styling - Official Add-on
Official F-Droid add-on for colors and fonts (long-press terminal to apply)
Install from F-Droid: https://f-droid.org/en/packages/com.termux.styling/ After install: 1. Long press inside Termux 2. Select More... 3. Select Style 4. Choose COLOR or FONT
Linux Distros

OS Installer Commands

Install full Linux distributions inside Termux using proot-distro

PD
Prerequisites - Install proot-distro
Required before installing any Linux distribution
pkg update && pkg upgrade -y pkg install proot-distro -y termux-setup-storage proot-distro list
UB
Ubuntu - Standard Release
Most popular Linux distro, great for beginners
proot-distro install ubuntu proot-distro login ubuntu apt update && apt upgrade -y apt install -y curl git build-essential
DB
Debian - Stable Release (bookworm)
Rock-solid stability, recommended for OpenClaw
proot-distro install debian proot-distro login debian apt update && apt upgrade -y apt install -y curl git build-essential sudo
KL
Kali Linux - Penetration Testing
Security testing tools: nmap, metasploit, sqlmap
proot-distro install kali proot-distro login kali apt update && apt upgrade -y apt install -y nmap metasploit-framework sqlmap hydra apt install -y curl git python3
AL
Arch Linux - Rolling Release
Cutting-edge packages, AUR access (AArch64 only)
proot-distro install archlinux proot-distro login archlinux --user root --shared-tmp pacman -Syu pacman -S sudo vim git curl base-devel
AP
Alpine Linux - Lightweight
Minimal resource usage, ideal for low-end devices
proot-distro install alpine proot-distro login alpine apk update && apk upgrade apk add bash nano wget curl git build-base
FD
Fedora - Version 39+
Latest features, 64-bit CPUs only
proot-distro install fedora proot-distro login fedora dnf update -y dnf install -y curl git gcc make
MG
Manage Distributions - Useful Commands
List, remove, backup, and manage installed distros
proot-distro list proot-distro remove ubuntu proot-distro backup ubuntu proot-distro restore ubuntu proot-distro reset ubuntu proot-distro clear-cache

Helpful Termux Commands

Everyday commands every Termux user should know

01
Basic Setup & Package Management
Essential first commands for any Termux user

02
File & Directory Management
Navigate, create, copy, and manage files
ls -la cd /storage/emulated/0/Download mkdir myproject && cd myproject touch main.py cp file.txt backup.txt mv old.txt new.txt rm unwanted.txt find . -name "*.py" grep "search" file.txt
03
Python Development
Set up Python, pip, and virtual environments
pkg install python -y python --version pip install flask requests numpy python -m venv myenv source myenv/bin/activate pip install kivy kivymd python main.py
04
Web Server & Node.js
Run web servers and Node.js apps on your phone
pkg install nodejs -y node --version npm init -y npm install express python -m http.server 8080 npx create-expo-app@latest myapp cd myapp && npx expo start

Network & Security Tools
Scanning, testing, and network analysis tools

Git & GitHub Commands
